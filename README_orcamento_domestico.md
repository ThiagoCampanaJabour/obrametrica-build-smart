Orçamento Doméstico & Simulador Energético — instruções

1) Para rodar localmente:

git checkout -b feat/orcamento-domestico
colar arquivos conforme estrutura e rodar:
npm ci
npm run dev

Abrir: http://localhost:8080/ferramentas/orcamento-domestico

2) Testes:
npm run test

3) PR:
Branch: feat/orcamento-domestico
PR title: feat: Orçamento Doméstico & Simulador Energético
Incluir screenshots (inputs + resultados + gráfico)
Incluir evidence que testes passam
