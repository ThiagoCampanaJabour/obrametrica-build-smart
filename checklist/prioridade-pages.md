# Checklist Prioritário — Preparação para AdSense / Conteúdo de Alto Valor

Este arquivo lista as páginas prioritárias para enriquecer em conteúdo, adicionar JSON‑LD, bylines, imagens otimizadas e preparar para re‑submissão ao Google AdSense.

## Ações gerais por página
- Garantir meta title (≤ 60 char) e meta description (≤ 155 char).
- H1 claro e estrutura de H2/H3.
- Conteúdo editorial mínimo (ver coluna min_words no CSV).
- JSON‑LD (Article ou SoftwareApplication) onde aplicável.
- Imagem destacada WebP (1200×630) com alt text.
- Autor (byline) + last_reviewed.
- Links internos para pelo menos 3 ferramentas relacionadas.

## Ações técnicas prioritárias
1. Implementar Privacy Policy, Cookie Policy e Terms of Use.
2. Implementar cookie consent (bloquear scripts de terceiros até consentimento).
3. Inserir ads.txt (placeholder) na raiz do site.
4. Marcar thin pages para noindex ou consolidar conteúdo.
5. Otimizar imagens (WebP + lazy loading).
6. Implementar JSON‑LD básico (Article/SoftwareApplication).
7. Verificar HTTPS, HSTS e performance (LCP < 2.5s target).

## Observações finais
Após aplicar as mudanças, gerar um “evidence pack” (screenshots, Lighthouse, Rich Results test) para re‑submissão ao AdSense.
